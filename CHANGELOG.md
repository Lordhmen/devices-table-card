# История изменений

## 0.1.0 — 2026-10-15

Первая версия.

- Режим `network`: сетевые устройства из `device_tracker` (отбор по `platforms` / `include` / `exclude`),
  колонки «Устройство / IP / Сеть / MAC / Статус», IP из DHCP-резерваций (`reservations_entity`),
  пометка случайных (локально администрируемых) MAC.
- Известные / неизвестные устройства по метке (`known_label`), кнопка в строке ставит или снимает метку.
- Режим `availability`: список устройств «не в сети» из атрибута сенсора, плитки по источникам (`sources`),
  фильтры по типу, кнопка «не отслеживать» ставит метку (`ignore_label`) на устройство.
- Сортировка по клику на заголовок (IP сортируется численно), фильтры-чипы со счётчиками, поиск, экспорт CSV.
- Тёмная и светлая темы через CSS-переменные HA, адаптивная вёрстка (на узкой карточке IP и сеть
  переходят под имя, MAC скрывается).
- Демо-страница `docs/demo.html` на вымышленных данных и скриншоты.
